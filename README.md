# Tutor

Tutor is a chat application that helps users learn English through conversation. Users can sign in, start chats, send messages, and use voice input while a tutor guides the learning experience.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm start
```

Run on a specific platform:

```bash
npm run android
npm run ios
npm run web
```

## Development

This project is built with Expo, React Native, TypeScript, and Expo Router.

Useful checks:

```bash
npm run typecheck
npm run lint
npm test
```

Run all checks:

```bash
npm run verify
```

## Configuration

The backend API address is defined in [`src/constants/addresses.ts`](src/constants/addresses.ts).
